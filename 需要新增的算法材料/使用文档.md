# iconmask.py — 自适应图标遮罩生成器

还原 MyDockFinder「全局图标遮罩」效果的独立小工具：给任意不规则、透明背景的 PNG 图标，自动套上圆角矩形面板（深色/浅色自适应）、按图标配色做径向光晕、加光泽与柔和阴影。

## 环境要求

- Python 3.10+
- Pillow（`pip install Pillow`）

## 基本用法

```bash
python iconmask.py 输入.png 输出.png [参数]
```

程序**不会修改原图**：先自动裁掉透明边距，再居中垫成方形画布，处理后的结果写到输出文件。

## 参数总览

| 参数 | 默认 | 说明 |
|---|---|---|
| `--shape` | `rect` | 面板形状：`rect` 圆角矩形 / `squircle` 超椭圆 / `circle` 圆形 |
| `--corner` | `0.22` | 圆角半径占边长比例（0.1 更方，0.5 更圆） |
| `--size` | 自动 | 输出边长（默认取图标最大边） |
| `--thresh` | `0.5` | 明暗分界：图标亮度高于它走浅色面板，低于走深色 |
| `--light-mix` | `0.90` | 浅色面板提白比例（1 = 纯白，越小越显色） |
| `--dark-mix` | `0.72` | 深色面板加深比例（1 = 纯黑，越小越显色） |
| `--bg` | `0.10` | **径向光晕浓度**（0~1），主调光晕浓淡 |
| `--gloss` | `0.16` | 顶部光泽强度 |
| `--icolight` | `0.08` | 图标本体提亮 |
| `--iconratio` | `0.66` | 图标占面板比例 |
| `--shadow-opacity` | `0.22` | 阴影浓度 |
| `--shadow-blur` | 尺寸×0.022 | 阴影模糊半径 |
| `--shadow-offset` | 尺寸×0.012 | 阴影向下偏移 |
| `--shadow-fade` | `0.25` | 阴影尾部衰减 |
| `--shadow-mode` | `icon` | 阴影轮廓来源：`icon` 图标本体 / `badge` 面板整体 |

## 示例

深色图标 → 深色面板（自动）：

```bash
python iconmask.py quark_src.png quark_final.png
```

浅色图标 → 浅色面板（自动）：

```bash
python iconmask.py lumina_src.png lumina_final.png
```

强制深色 / 强制浅色（按亮度阈值）：

```bash
python iconmask.py lumina_src.png lumina_dark.png --thresh 0.9
python iconmask.py lumina_src.png lumina_light.png --thresh 0.3
```

光晕更浓：

```bash
python iconmask.py lumina_src.png lumina_halo.png --bg 0.22
```

## 算法流程

1. **裁边**：去掉透明外围，避免把空白当颜色采样
2. **补方**：居中垫透明边成正方形画布（Dock 图标皆为方形）
3. **强调色**：对不透明像素做 alpha+饱和度加权平均，得到图标主色 `dom`
4. **明暗判定**：加权亮度 vs `--thresh` → 决定面板 = `dom` 的深色版（越深越好）或浅色版（越浅越好）
5. **径向取色**：从中心 360 度采样图标射线颜色（权重偏向外缘，半径 1.4 次幂），±10° 角度平滑
6. **背景合成**：面板单色为底，每个像素按其所在扇区颜色做微调（`--bg` 控强度），沿「图标边缘 → 面板边缘」带宽慢衰减（0.5 次幂）
7. **叠加层**：极淡纵向渐变 → 顶部光泽 → 图标本体 → 下方柔影
8. **遮罩裁剪**：所有层按形状 mask 剪裁，四角透明

## 常见问题

- **面板偏灰不够显色**：调低 `--light-mix`（浅色）或 `--dark-mix`（深色），或先确认 `dom` 输出是否正确
- **光晕太淡 / 太跳**：调 `--bg` 0.10~0.30；出现束状色柱时降低浓度并减小 `--corner` 外的角度平滑（代码内 `ang_smooth`）
- **方向对不上**：当前坐标已修正，绿在左就有绿晕在左；若升级代码请保持射线采样与像素角度使用同一坐标系
- **非正方形源**：自动居中方块化处理，输出始终是正方形贴图
